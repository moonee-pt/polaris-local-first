# 三模式规划（对话 / 小说 / 女性向音声台本）

> 状态：规划中（2026-10-12）。本文件记需求、已定口径与待办；三种模式的提示词草稿在 `work/prompt-drafts/`。

## 需求（用户原话要点）
1. 对话模式：活人感强，像真人聊天。
2. 小说模式：AI 第一人称写小说，用户负责引导、推动剧情。
3. 女性向音声台本：纯听；全用语言输出；用语言描述动作/场景细节让人想象；有对话留白回应。

## 已定口径
- 模式挂在**对话**上（不是角色上）；允许**对话内中途切**，只对之后的回复生效，切换时后台补一句极短的模式提醒，避免被旧历史带跑。
- 音声模式**这轮只做「话术台本」**（模型输出的台本格式）；朗读押后，做法定为：逐句/分段 TTS + 后台预生成 + 边听边生成。
- 对话模式提示词：`work/prompt-drafts/chat-mode-v4.txt`（已改到 v4）。
- 禁用套路（用户令）：陪伴台词、结尾反问钓话、安慰＋讲道理、客服腔/总结腔、金句格言；平时闲聊不加排版。
- 分两层：**执行归执行，说话归说话**——写代码/卡片/文档正常交付，真人感只要求「说话/解释」那层。
- 去 AI 味禁词表：`work/prompt-drafts/ban-list-ref.txt`（扒自酒馆预设）。
